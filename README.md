# Rayuk-creator.github.io

Questo repository serve solo a collegare l'app Android di «Matematica in gioco · Maths at Play» al suo sito:
contiene il file `.well-known/assetlinks.json`, che Google controlla per aprire l'app a tutto schermo.

Il gioco è in [Rayuk-creator/matematic](https://github.com/Rayuk-creator/matematic) e si gioca su
<https://rayuk-creator.github.io/matematic/>.

Non cancellare `.nojekyll`: senza quel file GitHub Pages nasconde la cartella `.well-known`.
